# Engineering Apps

Small, self-contained engineering explainers. Each app is a single HTML file with no build step: open it in a browser.

## Jet Engine Explorer

`jet-engine-explorer/index.html`

A scroll-driven, animated cutaway of six air-breathing engines: turbojet, turbofan, turboprop, turboshaft, ramjet and scramjet. Scroll through each engine station by station (intake, compressor, combustor, turbine, nozzle and so on) while the drawing highlights that section and shows representative gas temperature, pressure and speed.

- Particles flow through the engine, coloured by temperature or velocity
- Rotating spools (low- and high-pressure), propeller, gearbox, flames and shock waves are animated
- Click a part of the drawing to jump to its explanation
- Link straight to an engine with a hash, e.g. `index.html#scramjet`
- A comparison chart shows the flight Mach range each engine covers

Numbers are representative of each engine class, not of one specific model.
